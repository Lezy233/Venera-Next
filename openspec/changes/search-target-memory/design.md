# F8 设计

## D1 状态与范围

记忆是当前 appdata 数据目录内的搜索页用户选择，不是 SearchProfile 内容或默认配置。使用一个带版本的独立设置记录（建议 searchSelection），包含 mode=single/aggregated、sourceKey（保留最近单源）、profileId（合法空值代表明确选择全局设置）。有效空 ID 与从未保存必须可区分。读取做类型/版本校验；损坏记录回退默认，不写回清理其他字段。

无记录时保留现有初始化：defaultSearchTarget 为 _aggregated_ 则聚合，否则取有效默认来源或当前有序可搜索列表首项；方案取当前有效 defaultSearchProfile。有有效记忆时优先使用记忆。修改默认配置不覆盖已有记忆；记忆也不修改任何默认配置。记忆保存选择而非解析后的方案内容，重命名/更新同 ID 下次使用最新名称/内容。

## D2 控件动作

保留现有搜索页来源芯片、聚合复选框和方案下拉的含义：单源时点击来源记忆 sourceKey；聚合时来源芯片仍不可用。切聚合开关记忆模式且保留最近单源与方案 ID。选非空方案按现有行为进入聚合并记忆该 ID；选「全局设置」记忆 null，不擅自切换当前模式。切回单源使用保留来源并沿用现有默认 options 初始化。临时 options 不跨页面恢复。

用户明确改变上述选择即保存，无须先提交搜索。初始化、build、返回结果页、渲染外部固定来源结果均不覆盖记忆。搜索与历史点击取当前有效选择；聚合传正确 profileId，单源传正确 sourceKey 与正常 options。保持原搜索语言过滤、分页、快捷方式与创作者平台名称搜索参数。

## D3 失效与可见回退

来源按 searchSources 配置过滤并使用当前 registry 支持普通搜索的列表，身份按 key，不能用显示名匹配。被记忆单源卸载/禁用/不支持搜索时，实际目标回退该列表首项；列表为空时展示既有 No Search Sources、禁用启动和建议查询，不发生空断言。聚合的备用单源失效不阻止有效聚合。

所选方案删除/损坏时实际 profileId=null（全局设置），不得暗换另一个默认方案；单源状态下也校验其保留的方案 ID。控件附近持续本地化说明「上次来源不可用，已使用…」/「上次方案不可用，已使用全局设置」及必要的无来源状态；不在 build 反复 toast。恢复原 key/ID 后，在用户尚未明确新选择时可重新解析原记忆。回退本身不覆盖持久记忆；用户下一次明确选择保存当时有效完整选择并消除对应旧警告。已打开页面接收来源设置/方案变更后也须重算，不只重开时生效。仅名称变化不能触发来源误回退或重置 options。

## D4 可靠保存与归属

复用 appdata.updateSettings 的串行草稿与既有 SettingsRecoveryFailure 能力，为此记录使用独立 recoveryKey；检查其实际 publish-before-IO 语义，不以只改内存代替持久化。捕获提交时数据路径，入队后复核，旧页面/旧目录操作不得写到新目录。写入只拥有自己的设置记录，不覆盖默认配置、方案库、历史及并发其他设置。

最小实现可在保存期间禁用选择控件和搜索启动，成功后以持久结果确认；或保持交互但保证最新意图胜出，必须有快速连续选择验证。失败恢复到上次持久有效选择并显示可重试错误；补偿未完成时保持错误及禁用相关写入，提供明确恢复重试，恢复不自动重放原失败选择。appdata/syncdata 必需文件失败均不能当成功。目录切换后旧完成不能更新新页面状态。不扩充通用事务框架；若现有能力不满足需报告 architect。

## D5 UI 和验证

使用 ui-ux-pro-max 的既有 UI 缺陷检查：反馈靠近控件、可理解且可恢复，键盘焦点/禁用语义明确；沿用 design-spec.md §1–5 token/主题/断点及既有布局，不生成新视觉系统。新增文案 .tl + zh_CN/zh_TW。

真实组件自动化覆盖：

| 场景 | 必须核对 |
|---|---|
| 旧目录、无记录、坏类型/版本 | 默认目标/默认方案兼容，无写入污染 |
| 聚合+方案A→关闭/重开→新搜索 | 控件恢复，真实路由/请求 profileId/来源/options 正确且一次 |
| 单源B→关闭/重开；再切聚合/单源 | sourceKey 保留；明确 null 方案不会复活默认方案 |
| 来源A/B同显示名，记忆B失效/恢复 | 按 key 隔离，回退可见且安全，空来源无请求/空断言 |
| 已开页删除/改名/更新方案，变更来源配置 | 解析及时刷新；删除回退全局，不换默认，既有显式入口不污染记忆 |
| 真实保存失败/补偿失败/恢复/目录切换 | 错误真实，磁盘与内存一致，不误报成功，不丢其他字段 |
| 快速选择与无变化返回 | 最新有效选择稳定，无重复请求或初始化覆盖 |

GUI 使用生产 SearchPage 与隔离 fixture，验证聚合方案、单源、失效提示，实际退出进程后新 PID 重启恢复并提交一次搜索核对目的页。至少 expanded 与 compact 两宽度，浅深主题及键盘操作不新增溢出。截图只/tmp，鼠标事件后等待稳定再截。正常 main/runner 不为 fixture 修改，最后正常构建并停自己的 fixture。
