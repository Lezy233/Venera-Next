## ADDED Requirements

### Requirement: 最后搜索选择持久化

搜索页 MUST 记忆最后明确选择的聚合/单源模式、最近单源 sourceKey 与搜索方案稳定 ID，MUST 区分明确空方案与从未记忆；关闭重开、新搜索及应用重启 MUST 恢复有效选择。临时关键词、options、过滤条件及页码不在本能力范围。

#### Scenario: 聚合与单源重进

- **WHEN** 用户选择聚合与方案A后关闭、重开、重启，随后切单源B再重启
- **THEN** 分别恢复聚合+A及单源B；搜索实际采用对应身份与有效选项，单次操作只启动一次

#### Scenario: 明确全局设置

- **WHEN** 有默认方案A的用户明确选择全局设置并重开搜索页
- **THEN** 当前方案仍为空，不重新选择默认方案A

### Requirement: 记忆与默认配置隔离

无有效记忆时 MUST 兼容当前默认目标和默认方案初始化；有效记忆 MUST 优先，MUST NOT 修改默认目标、默认方案、方案内容或其他入口显式参数。方案 MUST 按 ID 解析最新内容。

#### Scenario: 修改默认与显式入口

- **WHEN** 用户已有记忆B，之后修改默认为A并点击收藏创作者平台名称打开来源C普通搜索
- **THEN** C按既有显式参数搜索；下次搜索页仍恢复B，默认A与方案内容不受记忆写入影响

### Requirement: 失效选择安全回退

来源失效 MUST 按当前有序可搜索来源列表首项回退，方案失效 MUST 回退全局设置，并在控件附近明确本地化说明；MUST 按 key/ID 区分身份。无来源 MUST 保持空态且禁止请求。已开页面发生配置变动 MUST 及时重算。自动回退 MUST NOT 覆盖原记忆，用户明确新选择后才保存有效完整选择。

#### Scenario: 同名来源失效

- **WHEN** 记忆来源B失效且另一个来源A具有相同显示名
- **THEN** 按列表规则回退并说明，不能按显示名偷换身份；无有效来源时不请求且不抛空断言

#### Scenario: 方案删除与恢复

- **WHEN** 已打开搜索页所选方案被删除，随后恢复同ID，期间用户未选择其他配置
- **THEN** 先可见回退全局设置，再能解析恢复的ID，默认方案不会被擅自套用

### Requirement: 选择可靠保存与失败反馈

选择写入 MUST 使用串行持久化并保护原数据目录和字段所有权；MUST 保持最新明确意图。失败 MUST 显示可恢复错误并保留此前有效状态，补偿未完成 MUST 保持错误并禁止相关写入，恢复 MUST NOT 自动重放失败选择；其他设置 MUST 保留。UI MUST 遵循现有设计契约，新文案 MUST .tl 并提供 zh_CN/zh_TW。

#### Scenario: 保存故障与目录切换

- **WHEN** appdata或syncdata写入失败，或选择排队时用户切换数据目录
- **THEN** 不显示保存成功、不污染新目录或其他字段，明确失败/恢复状态并可重试
