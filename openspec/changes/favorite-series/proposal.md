# Proposal

## Why

BACKLOG F5：同一系列作品常分散在多个来源和现有收藏文件夹中。当前收藏文件夹是独立收藏集合，无法表达跨来源的手动系列关系，All 视图也会按来源身份去重，不能作为系列模型复用。

## What Changes

- 新增与收藏文件夹正交的本地系列实体与系列成员映射；成员沿用完整 `(id, type)` 收藏身份，不按标题或作者自动猜测。
- 支持系列新建、重命名、删除、排序，以及把已收藏作品加入/移出系列。
- 收藏页侧栏提供系列入口和系列内容视图；系列视图保留跨来源成员，不使用 All 视图的身份去重语义。
- 系列数据随现有 `local_favorite.db` 快照同步；旧导入数据保持未分组。
- 新增 UI 文案经 `.tl`，并补齐 `zh_CN`、`zh_TW`。

## Out of Scope

- 不自动按标题、作者或标签匹配系列。
- 不把现有收藏文件夹改名或迁移为系列；文件夹仍表示收藏容器。
- 不改变追更、稍后阅读、网络收藏夹和现有文件夹的语义。
- 不新增云端系列协议；WebDAV/数据库整体同步沿用现有通道。
