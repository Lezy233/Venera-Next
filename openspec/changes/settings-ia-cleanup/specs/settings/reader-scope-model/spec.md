# Spec Delta

## Purpose

阅读设置的作用域选择能力：用户通过显式选择器切换"默认 / 此设备 / 此漫画"作用域，页面内容随作用域整体切换，消除三层作用域并列暴露导致的误改与评估鸿沟。

## ADDED Requirements

### Requirement: 显式作用域选择器

阅读设置页 MUST 提供明确的作用域选择控件（默认 / 此设备 / 此漫画），整页设置项随所选作用域整体切换，而不是在同一平面混排多个作用域的条目。

#### Scenario: 从阅读器进入

- **WHEN** 用户在阅读器内打开设置面板
- **THEN** 作用域选择器 MUST 默认选中"此漫画"，且页面只显示该漫画作用域下的设置项

#### Scenario: 从全局设置进入

- **WHEN** 用户从设置主导航进入阅读设置
- **THEN** 作用域选择器 MUST 默认选中"默认"，不出现"此设备/此漫画"层级的残留状态混入

### Requirement: 作用域状态提示

当所选作用域存在覆盖值时，界面 MUST 提供一键恢复该作用域默认值的能力；"此漫画"面板中的跨层级提示 MUST 描述具体动作（例如"修改默认设置请前往 设置 → 阅读"），不得出现指向不明的文案。

#### Scenario: 重置单部漫画设置

- **WHEN** 用户在"此漫画"作用域下点击重置
- **THEN** 仅清除该漫画的覆盖值，默认设置保持不变

### Requirement: 防误改确认

从"默认"作用域切换到"此漫画"并修改任意设置项后，界面 MUST 有持久可见的标识（如保存状态条）表明当前修改作用于单部漫画层级。

#### Scenario: 评估改动影响范围

- **WHEN** 用户修改了一项设置
- **THEN** 用户能够明确说出该改动作用于哪一层（默认 / 此设备 / 此漫画）
