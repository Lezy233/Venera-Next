# Spec Delta

## Purpose

统一的远程存储（WebDAV）连接配置能力：一份连接信息被数据同步、漫画存档备份、WebDAV 漫画库三个用途共享，消除重复配置，让用户对"配置一次，处处可用"建立正确预期。

## ADDED Requirements

### Requirement: 单一连接配置

系统 SHALL 仅保存一份 WebDAV 连接配置（URL、用户名、密码），供数据同步、漫画存档备份、WebDAV 漫画库三个用途共享。

#### Scenario: 首次配置

- **WHEN** 用户在设置中完成一次 WebDAV 连接配置（连接测试通过并保存）
- **THEN** 数据同步、漫画存档备份、WebDAV 漫画库三个用途均可直接使用该连接，无需再次填写

#### Scenario: 升级迁移

- **WHEN** 应用从旧版本升级，存在历史遗留的多份 WebDAV 配置
- **THEN** 系统 MUST 保留各用途的启用状态与排他性设置，连接信息迁移到共享配置；若旧配置间连接信息不一致，MUST 以"数据同步"一份为准并在首次进入时提示用户确认

### Requirement: 用途级启停与状态可见

每个用途 MUST 能独立启用/停用；每个用途的入口 MUST 显示当前共享连接状态（已配置 / 未配置），未配置时点击跳转连接配置。

#### Scenario: 未配置连接时使用备份

- **WHEN** 共享连接未配置且用户点击"漫画存档备份"
- **THEN** 系统 MUST 先引导用户完成连接配置，而不是弹出一份独立的空白表单

#### Scenario: 查看状态

- **WHEN** 用户在 App → Data 分类浏览
- **THEN** 每个远程存储用途的副标题 MUST 显示连接是否已配置

### Requirement: 用途语义说明

每个用途入口 MUST 有一句话说明其用途边界（同步哪些数据 / 备份什么格式 / 在线阅读的支持范围）。

#### Scenario: 区分同步与备份

- **WHEN** 用户阅读"数据同步"与"漫画存档备份"的说明文字
- **THEN** 用户能够说出前者同步应用设置与收藏数据，后者仅备份 CBZ 漫画存档
