# Spec Delta

## Purpose

保存反馈的呈现能力：保存状态（保存中/成功/失败）以不占用正文布局的覆盖层形式呈现，消除保存期间正文下移-回弹的视觉缺陷，同时保持保存反馈的可见性与现有保存语义。

## ADDED Requirements

### Requirement: 保存反馈不占正文布局

保存反馈（保存中/成功/失败状态条）MUST NOT 通过插入、移除或改变高度的方式影响正文内容的布局；保存期间正文关键 Widget 的坐标 MUST 与保存前一致。

#### Scenario: 收藏页切换文件夹

- **WHEN** 用户在收藏页切换文件夹触发保存
- **THEN** 保存进行中正文布局坐标保持不变，不出现下移-回弹

#### Scenario: 阅读模式修改设置

- **WHEN** 用户在设置 → 阅读分类修改任意阅读模式设置触发保存
- **THEN** 保存进行中及保存结束后，设置项坐标均与修改前一致

### Requirement: 保存反馈可见性

覆盖层呈现 MUST 保留三态反馈：保存中（进行中指示）、保存成功、保存失败（含重试入口）；用户 MUST 能在保存进行中明确感知保存状态。

#### Scenario: 保存失败

- **WHEN** 保存失败
- **THEN** 覆盖层反馈 MUST 显示失败状态并提供与现状一致的重试入口

### Requirement: 保存语义不变

覆盖层改造 MUST NOT 改变现有保存语义：`saveSetting` 的 admission 机制、保存中禁用修改（protect）、离开页面等待保存完成（leave）的行为与改造前一致。

#### Scenario: 保存中继续修改

- **WHEN** 保存进行中用户尝试修改同一页面的其他设置项
- **THEN** 修改被禁用或按现有 protect 语义处理，与改造前行为一致
