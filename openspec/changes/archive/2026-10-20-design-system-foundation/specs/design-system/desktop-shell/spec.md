# Spec Delta

## Purpose

桌面外壳规范：窗口框架、顶栏、命令中心、侧栏的布局、密度与交互规则，浅色极简语言在壳层的唯一定义来源（阅读器全屏场景同样跟随本规范的主题规则，不设例外）。

## ADDED Requirements

### Requirement: 外壳结构一致

桌面端窗口 MUST 由统一的外壳组件构成（自定义标题栏 + 顶栏 + 导航侧栏 + 内容区），各页面 MUST NOT 自行实现第二套窗口级框架。

#### Scenario: 任意页面

- **WHEN** 用户在桌面端浏览任意页面
- **THEN** 窗口控件、顶栏、导航的位置与行为一致，无页面私造的标题栏

### Requirement: 命令中心行为

顶栏搜索框（命令中心）MUST 显示与当前上下文匹配的提示语（已实现：全局搜索/搜索收藏/搜索章节），且在窗口宽度低于展开断点时隐藏。

#### Scenario: 上下文切换

- **WHEN** 用户从收藏页切换到阅读器
- **THEN** 命令中心提示语随之变化，无需用户猜测当前搜索目标

### Requirement: 侧栏控件状态可见

侧栏开关按钮在不可用页面 MUST 显示为禁用态而不是消失，且禁用时有 tooltip 说明原因。

#### Scenario: 非收藏页

- **WHEN** 用户在非收藏页查看顶栏侧栏开关
- **THEN** 按钮可见但置灰，tooltip 说明"仅收藏页可用"

### Requirement: 装饰克制

壳层 MUST NOT 使用移动端装饰（如列表选中项尾随箭头图标）；强调色使用遵循 token 系统。

#### Scenario: 设置分类选中态

- **WHEN** 用户在桌面端选中一个设置分类
- **THEN** 选中态为底色+左侧边条（现状保留），无尾随箭头
