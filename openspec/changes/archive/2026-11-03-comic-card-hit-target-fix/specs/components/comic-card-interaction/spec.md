# Spec Delta

## ADDED Requirements

### Requirement: 标题与封面主动作一致

所有显示漫画标题的卡片 MUST 允许在可见标题首行及后续显示行、封面执行同一既有主动作且恰好一次，包含详细/简略/画廊与带标题简卡。装饰状态 MUST NOT 阻断本卡片可见标题的主动作；MUST 保留作品id、sourceKey与原路由语义，MUST NOT 命中邻卡。

#### Scenario: 标题首行与装饰

- **WHEN** 用户点击带收藏/进度/更新装饰的长标题首行任一可见文字区域，或其第二行/封面
- **THEN** 对应卡片主动作恰好执行一次，不因装饰覆盖而无响应，不导航到其他作品

#### Scenario: 聚合简卡

- **WHEN** 用户点击聚合结果中带标题简卡的标题或封面
- **THEN** 均打开该作品在对应来源的详情且仅一次

### Requirement: 收藏与独立交互保持

卡片修复 MUST 尊重当前页面主动作：收藏普通模式遵守详情/直接阅读偏好，多选模式仅切换选择。右键、显式菜单/独立按钮 MUST 保持自身动作且不得附带主动作；排序拖动、既有键盘与按压反馈 MUST 保留。

#### Scenario: 收藏点击偏好与多选

- **WHEN** 用户在收藏页点击标题或封面，或已进入多选
- **THEN** 普通模式依偏好进入详情/阅读，多选只切换该作品选择，不打开详情或阅读器

#### Scenario: 菜单和拖动

- **WHEN** 用户右键、执行复制等独立菜单动作或在排序页拖动卡片
- **THEN** 保持既有操作，不额外触发详情/阅读导航，不破坏拖动


### Requirement: 窄brief状态组合保持可操作

brief卡片宽度小于88px时 MUST 复用既有18px紧凑状态徽章，避免收藏/旧数字进度/更新组合在72px受支持布局中横向溢出。其他布局参数 MUST 保留，MUST NOT 通过提高验证最小宽度规避该组合；非窄brief及gallery现有尺寸语义 MUST 保持。

#### Scenario: 72px三状态与阈值

- **WHEN** 72px或87px的brief同时显示收藏/旧数字进度/更新，随后卡宽变为88px
- **THEN** 窄卡使用18px紧凑徽章并无横向溢出，标题/封面主动作与来源保持正确；88px起沿用brief原徽章尺寸与既有布局
