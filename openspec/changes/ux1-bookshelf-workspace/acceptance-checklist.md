# UX1 owner 验收清单

> 用途：生产实施完成后逐场景验收。当前所有项目均未执行；勾选只代表对应生产功能已验证，不代表本清单已创建即通过。自动化证据由 executor/architect 提供，owner 重点核对实际操作是否符合预期。

## A. 书架壳层与收藏

- [ ] A1 桌面左侧是书架导航，右侧顶栏包含搜索、历史与标签；macOS 交通灯右侧可收起侧栏。
- [ ] A2 收起/展开侧栏后，当前漫画、滚动、多选和焦点不丢失，没有第二套窗口框架或分屏。
- [ ] A3 窄窗口手动打开侧栏时覆盖内容；点击外部或 Escape 关闭；恢复宽窗口后保留此前的展开/收起偏好。
- [ ] A4 收藏默认舒适密度；紧凑后同屏作品增加，但文字、作者和更新信息仍清楚。
- [ ] A5 作者栏三态、每栏独立排序、侧栏大分类折叠、系列与收藏身份均保持原行为。

## B. 漫画点击、多选与拖放

- [ ] B1 搜索结果默认是封面平铺，不再以整行文字列表作为主要形态。
- [ ] B2 「进入详情／直接阅读」设置在收藏、搜索及其他漫画列表一致生效。
- [ ] B3 卡片复选框平时不干扰画面，悬停或键盘聚焦时出现，选中后常驻；点击它不会打开漫画。
- [ ] B4 已有多选时，点击另一张卡片主体仍按设置正常打开，不会意外清空或替换选择。
- [ ] B5 Escape 在没有更高优先级浮层时清空所有选择，焦点回到合理位置。
- [ ] B6 多选拖入标签栏后每部漫画形成一个后台标签，仍停留原搜索；不使用拖放也有按钮/菜单/键盘路径。
- [ ] B7 拖动中 Escape 可取消且不创建标签；拖放不改变收藏、作者排序和来源设置。

## C. 临时预览

- [ ] C1 Space 打开当前漫画预览，可查看概览、目录与详情，不创建标签。
- [ ] C2 左右方向键切换预览漫画；Space 或 Escape 关闭后焦点回到原卡片，滚动与多选不变。
- [ ] C3 预览中 Enter 在当前标签打开，并能通过返回恢复原搜索。
- [ ] C4 预览中 Cmd/Ctrl+Enter 在后台新标签打开，不抢占当前页。
- [ ] C5 窄窗口中预览内容可滚动、关闭入口可见；减少动画时操作立即完成。

## D. 多标签、历史与资源

- [ ] D1 两个搜索标签可分别保留关键词、筛选、多选和滚动；详情与阅读标签保留各自章节、页码和展开状态。
- [ ] D2 标签内返回按钮与 Alt+Left 回到原搜索并恢复现场；返回不会关闭标签。
- [ ] D3 标签栏可用触摸板横向滚动和「全部 N」列表，没有左右滚动箭头；列表能激活任何标签。
- [ ] D4 当前标签关闭按钮常驻，其他标签在悬停/焦点内显示关闭按钮，点击区域稳定不跳动。
- [ ] D5 关闭当前标签默认回到最近浏览；设置可改为右侧或左侧；后台未查看标签不会进入最近浏览。
- [ ] D6 后台创建多部详情时没有整批加载；首次激活才加载对应详情，后台阅读器休眠且页码保留。
- [ ] D7 大量标签切换、关闭和恢复后不出现明显重复请求、所有阅读器同时渲染或现场静默丢失。

## E. 重启与设置

- [ ] E1 默认启动恢复上次标签：标签顺序、当前标签、搜索筛选、返回栈、多选、滚动、详情展开和阅读页码正确。
- [ ] E2 恢复后只立即加载当前标签，其他标签首次激活时再加载。
- [ ] E3 设置为「从收藏首页开始」时，当前会话不会立即清空；下次启动不自动恢复上次标签。
- [ ] E4 收藏密度、详情层级、关闭跳转和启动策略在重进与真实重启后保持。
- [ ] E5 工作区快照损坏或写入失败时有可理解反馈和安全回退，不白屏、不误删收藏或阅读进度。
- [ ] E6 验收包含实际终止进程和新 PID 重启，而非只重新构建页面或重开内存状态。

## F. 详情与搜索反馈

- [ ] F1 详情默认信息优先，直接看到完整元数据和简介；继续阅读、收藏和章节仍可用。
- [ ] F2 切换阅读优先后继续阅读和章节靠前，「作品详情与来源」默认收起且可展开；功能没有减少。
- [ ] F3 收藏切换状态清楚，切换详情层级或标签不会重置收藏与滚动现场。
- [ ] F4 首次加载显示同尺寸网格骨架；更新中旧结果仍可打开。
- [ ] F5 无结果时保留关键词和筛选，可清空筛选或尝试全部来源。
- [ ] F6 更新失败时保留旧结果，明确可能不是最新，可打开漫画并重试，不反复弹 toast。

## G. 阅读器

- [ ] G1 普通阅读保留标签，沉浸阅读隐藏标签；切换后漫画、章节、页码和阅读方案不变。
- [ ] G2 单击漫画任意位置可切换阅读工具，不再等待指针闲置 2 秒。
- [ ] G3 点击章节、菜单、按钮或文本控件不会额外触发漫画单击。
- [ ] G4 工具显示或隐藏时底部始终只有一条进度；隐藏工具只保留精简进度。
- [ ] G5 章节浮层覆盖右侧且不压缩漫画；沉浸中第一次 Escape 关浮层，第二次才退出沉浸。
- [ ] G6 浅深主题下阅读器 chrome 都跟随应用，无深色例外；减少动画不影响阅读和翻页。

## H. 全局质量与交付

- [ ] H1 仅用键盘可完成侧栏、搜索、多选、预览、标签、详情和阅读工具主要流程，焦点始终可见且不被吞掉。
- [ ] H2 expanded/medium/compact、150% 大文字、超长名称和简繁文案无溢出，完整名称可获取。
- [ ] H3 hover、pressed、selected、focus、disabled、加载、空态和失败反馈一致；强调色不染封面或整片内容。
- [ ] H4 手动和系统减少动画均生效，功能不消失、操作不等待动画。
- [ ] H5 新增文案均有 zh_CN/zh_TW；受影响既有测试通过且新增测试 0 skip；analyze 50 项基线零新增。
- [ ] H6 正常 main 构建、真实重启、fixture/进程清理和保护文件 diff 均有证据；截图与临时 harness 未入库。
- [ ] H7 architect 独立复核通过，delivery 中的命令、计数、源码 SHA 和局限完整；owner 验收后才归档推送。
