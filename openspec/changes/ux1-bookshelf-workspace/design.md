# UX1 A 书架型工作区设计与验收边界

## D1 已确认方向与默认值

本设计以 `explorations/ux1-directions` 为交互探索依据，以 owner 已确认的选择为准；探索稿中的配色、封面和图标不是生产视觉资产。

| 项目 | 确认结果 |
|---|---|
| 整体结构 | A 书架型；可收起导航侧栏 + 右侧工作区 |
| 对照方式 | 多标签，不分屏 |
| 收藏密度 | 默认舒适；紧凑为可选设置 |
| 详情层级 | 默认信息优先；阅读优先为可选设置 |
| 关闭当前标签 | 默认最近浏览；可设置右侧或左侧 |
| 应用启动 | 默认恢复上次标签；可选择从收藏首页开始 |
| 漫画主体点击 | 遵循全局设置进入详情或直接阅读，适用于所有漫画列表 |
| 阅读工具 | 单击漫画任意位置切换，不使用闲置 2 秒计时 |
| 阅读进度 | 底部始终只有一条；隐藏工具时仅保留精简进度条 |

## D2 框架容纳检查与契约迁移

BACKLOG 的锚点机制要求先核对 `design-spec.md`。原契约 §4/§7.1 的桌面固定 48px 图标侧栏不能容纳 A 书架导航，§7.3 的宽屏列表/详情并排与「多标签、不分屏」冲突，§4/§7.4 的阅读器一律无壳层与「普通阅读保留标签」冲突。

planner 已在本次规划中修订 §1、§3、§4、§7.1、§7.3、§7.4：桌面 medium/expanded 使用可收起书架侧栏，compact 桌面使用覆盖侧栏；工作区以标签切换代替并排对照；普通阅读保留标签，沉浸阅读才隐藏工作区 chrome。executor 必须在这些条款生效后实施，不得自行修改正式契约或新增例外。

现有 token、断点入口、语义颜色、Material Icons、`.tl`、收藏/搜索/阅读业务契约继续有效。新增侧栏、标签或控件尺寸必须先使用或补充 `AppSizes`/`AppSpacing` 等 token；不得在业务代码中写裸断点、硬编码颜色或另一套窗口框架。

## D3 书架壳层、顶栏与窄窗口

桌面结构按左右划分：左侧是全局搜索、收藏及既有导航分组，右侧是当前工作区。顶栏属于右侧工作区，不横跨侧栏；搜索控件使用轻量输入框而非孤立的重型按钮。macOS 交通灯右侧有侧栏开关；侧栏展开时，工作区仍需有可发现的收起入口。任何页面不得自造第二套窗口标题栏。

宽窗口记住用户手动展开/收起偏好。进入窄窗口时自动退出侧栏，但不得覆盖宽窗口偏好；用户手动打开后，侧栏以浮层覆盖内容并提供遮罩，点击外部或 Escape 关闭。恢复宽窗口后还原此前偏好。侧栏收起、覆盖和还原不得重建当前标签内容或丢失滚动、多选和焦点现场。

搜索平铺与收藏网格在窄窗口至少保留两列可读封面；极小宽度若现有断点无法保持可用，应通过既有响应式契约处理，不得溢出或把文字缩到 10px 以下。标准文字下卡片与标签长名称单行省略，悬停可查看完整名称；150% 大文字下卡片统一预留两行标题，导航与控件增加高度，次要内容允许换行或进入菜单。

## D4 漫画平铺、主体点击与多选

搜索结果默认使用封面平铺，收藏沿用作者 shelf 和封面网格；不以整行文字列表作为搜索默认形态。漫画主体的单击行为读取同一全局设置：进入详情或直接阅读。该设置扩展现有「设置 → 本地收藏 → 点击收藏」语义到搜索及其他漫画列表，不改变复选框、菜单、拖动手柄等独立命中区。

复选框位于卡片右上角，默认不占据正文空间。指针悬停或键盘焦点进入卡片时显现；选中后常驻，并提供勾选图形、选中描边及语义状态，不能只靠颜色。点击复选框只切换选择，不打开漫画；点击主体仍执行全局点击行为。Escape 在没有更高优先级浮层时清空所有选择并返回合理焦点。

多选漫画可整体拖到标签栏，每部漫画形成一个后台详情标签，当前搜索页保持激活。拖放不是唯一入口：必须同时提供右键或按钮以及 Cmd/Ctrl+Enter 等键盘路径。拖动中 Escape 取消且不创建标签；放置只改变标签，不修改收藏身份、作者栏顺序或来源配置。

## D5 多内容栈、历史、关闭与资源生命周期

每个标签拥有独立内容栈和稳定身份，至少保存页面类型与实体身份、来源/方案上下文、关键词与筛选、多选、滚动位置、焦点返回目标、详情展开状态、阅读章节和页码。切换标签只改变当前可见栈，不得把各标签压成只保存标题的路由记录。

从搜索进入详情时，当前标签内建立返回关系；顶栏返回按钮和 Alt+Left 回到原搜索，恢复筛选、多选、滚动与焦点。返回不等于关闭，不得移除该标签的其他工作现场。Enter 与预览的当前标签打开共用这一规则；Cmd/Ctrl+Enter 和后台打开创建独立标签，不抢占当前页。

标签栏支持触摸板/指针横向滚动和「全部 N」列表，不增加左右滚动箭头。全部列表显示完整标题、当前状态与待激活状态，并可键盘选择。当前标签关闭按钮常驻；非当前标签关闭按钮在悬停或焦点内显现，保留稳定命中区域，避免布局跳动。Cmd/Ctrl+T 新建标签，Cmd/Ctrl+W 关闭当前标签，Cmd/Ctrl+Tab 循环切换；不得覆盖文本输入与系统级冲突处理。

关闭当前标签默认激活最近浏览标签，可在设置中改为右侧或左侧。最近浏览顺序只记录实际查看过的标签；后台创建但从未激活的标签不进入该顺序。没有可用目标时显示可继续操作的空态，不得留下空白死路。关闭非当前标签不抢占当前内容。

后台详情在首次激活时才加载；后台阅读器休眠并保留章节和页码。图片与可共享数据复用既有缓存，不为每标签重复建立无界资源。标签数量增加不得导致整批网络请求、所有阅读器同时渲染或已有关闭规则失效；具体上限与回收策略如需要，必须保留用户现场并另行可见说明，不得静默丢弃。

## D6 临时预览与键盘焦点

Space 从当前漫画打开临时预览，展示封面、概览、目录与必要详情。预览不是标签，不进入标签历史，也不自动发起完整详情页的所有操作。左右方向键在同组漫画间移动预览目标；再次 Space 或 Escape 关闭，焦点回到原卡片，滚动和多选不变。

Enter 将预览漫画在当前标签打开；Cmd/Ctrl+Enter 在后台新标签打开。关闭预览不能误触底层卡片打开。预览浮层遵循真实浮层的 token、焦点约束和减少动画规则；窄窗口保证内容可滚动、关闭入口可见，不能用位移动画阻塞操作。

## D7 详情层级与相关设置

两种详情层级必须保留同一组功能：标题、作者、来源、分类、连载状态、继续阅读、收藏、简介和章节，只改变顺序与默认展开程度。

- **信息优先（默认）**：较大封面、完整元数据与简介直接显示，继续阅读、收藏和最近章节随后出现。
- **阅读优先**：继续阅读、收藏与最近章节优先，完整简介和来源放入默认收起的「作品详情与来源」区域；用户可手动展开。

收藏切换有明确 pressed/selected 状态，不能因切换层级或标签而重置。详情标签独立保留滚动与展开状态。收藏密度默认舒适；紧凑只增加同屏作品并减少间距，不缩小文字、不隐藏作者与更新信息，也不改变作者栏三态和独立排序。

## D8 阅读器 chrome 与 Escape 顺序

普通阅读保留工作区标签；沉浸阅读隐藏标签及其他非必要工作区 chrome。两种模式都通过单击漫画任意位置切换阅读工具，不再使用指针闲置 2 秒自动隐藏。单击独立按钮、菜单、章节浮层或文本控件不得冒泡成漫画切换。

底部始终只有一个进度组件。工具展开时显示完整阅读工具与同一进度组件；工具隐藏时只保留精简进度，不叠加第二条进度。章节使用右侧浮层覆盖漫画，不改变页面尺寸。

阅读器 Escape 顺序固定：先关闭章节等浮层；沉浸模式下再退出沉浸并恢复标签；普通模式工具隐藏时可找回工具。不得一次按键同时关浮层又退出模式。普通/沉浸切换保留漫画身份、章节、页码、阅读方案绑定与滚动/翻页状态。阅读器 chrome 跟随应用浅深主题，不恢复深色例外。

## D9 启动恢复、设置与失败边界

启动策略为本机工作区偏好，默认 `restore`。恢复上次标签时，还原标签顺序、当前标签及各标签的搜索筛选、返回栈、多选、滚动、详情展开和阅读页码；只立即加载当前标签，其余首次激活时再加载。不得把恢复现场理解为重启后同时请求所有来源。

选择 `fresh` 后，下次启动只打开收藏首页，不自动恢复上次标签；修改设置时不得立即清除当前会话。设置保存、启动快照和偏好写入必须复用项目可靠持久化机制，拥有版本、稳定身份、数据目录归属与失败反馈。快速操作和异步完成不得让旧回调覆盖新意图。

缺失或损坏的工作区记录应安全回退到可用首页并给出可理解反馈，不能白屏、循环恢复或误删收藏/阅读进度。工作区快照只保存导航与视图现场，不成为收藏、搜索方案或阅读进度的唯一数据源。真实验收必须终止进程并以新 PID 重启，不能只重新构建内存状态。

## D10 视觉、状态反馈与可访问性

遵循 `design-spec.md` §1/2/3/5/6/7：现代极简，中性 surface，字重、留白与 1px 分隔线建立层级；动态取色是唯一强调色来源，只用于当前位置、焦点、主操作与进度，不染封面或整片内容。探索稿的雾蓝、青绿、暖黄只是机制示意。

hover、pressed、selected、focus、disabled 必须有一致且可区分反馈；纯图标按钮有 tooltip 和语义名称。键盘焦点不被浮层、标签切换、多选或重启恢复吞掉。所有新增用户可见文案走 `.tl` 并补 zh_CN/zh_TW。

首次加载使用与结果同尺寸的网格骨架；更新中保留旧结果和打开能力；无结果保留关键词与筛选并提供清空/全部来源恢复；来源更新失败保留旧结果，明确可能不是最新，仍允许打开和重试。加载与失败状态不得通过重复 toast 或在 build 中循环提示。

动效只说明预览、覆盖侧栏和阅读工具的状态变化，使用 motion token；多选、标签切换与翻页立即响应。手动及系统减少动画都取消位移、淡入与循环动画，不隐藏功能、不延迟操作。

## D11 分阶段实施与证据

1. **契约与基座**：更新设计契约，建立 A 壳层、收藏首页和作者 shelf 小切片；先验证密度、反馈、窄窗和既有收藏业务。
2. **F1 多内容栈**：实现标签身份、每栈现场、历史、关闭与恢复；先完成真实存储和生命周期，再扩展入口。
3. **F2 临时预览**：实现 Space/Enter/Cmd/Ctrl+Enter、焦点归还和拖放等价入口。
4. **搜索与详情**：平铺、多选、状态反馈、信息/阅读层级及设置作用范围。
5. **阅读器与全局收尾**：普通/沉浸、单击工具、单进度、Escape、主题和减少动画；执行全量受影响回归。

每阶段必须包含真实生产控件行为测试和 GUI 走查，覆盖 expanded/medium/compact、浅深主题、150% 大文字、键盘和减少动画。工作区恢复必须有真实磁盘重载与新 PID 重启；资源规则用请求/加载计数证明，不以性能印象代替。新文案、保护测试、analyze 基线 50 项零新增、正常构建和 fixture 清理均按 AGENTS 执行。

executor 逐项更新 tasks 备注并交付命令、通过/失败/skip、保护 diff 与源码 SHA；architect 独立复核前不提交，owner 验收前不归档、不推送。当前机器无编译运行环境时只完成规划，不得虚称已运行 Flutter 验证。
