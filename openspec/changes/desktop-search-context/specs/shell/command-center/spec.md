# Spec Delta

## Purpose

命令中心的统一搜索能力：顶栏搜索框的提示语与行为在全局搜索、收藏过滤、章节过滤三个上下文一一对应，输入即反馈，消除同一 affordance 行为漂移。

## ADDED Requirements

### Requirement: 行为与提示语一致

命令中心在任一上下文中的行为 MUST 与其提示语描述一致：提示"搜索章节"时必须执行章节过滤，提示"搜索收藏"时必须执行收藏过滤，提示"搜索"时打开全局搜索。

#### Scenario: 阅读器内过滤章节

- **WHEN** 用户在阅读器内于命令中心输入章节关键词
- **THEN** 章节列表实时过滤，回车跳转到首个匹配章节

#### Scenario: 空输入回退

- **WHEN** 用户在收藏页清空命令中心输入
- **THEN** 收藏列表恢复完整内容，提示语保持"搜索收藏"

### Requirement: 快捷键与命令中心对齐

Ctrl/Cmd+F 聚焦命令中心后，其行为 MUST 与直接点击命令中心一致（同一上下文分流）。

#### Scenario: 阅读器内快捷键

- **WHEN** 用户在阅读器内按 Ctrl/Cmd+F 并输入
- **THEN** 与点击命令中心输入的效果完全相同

### Requirement: 反馈闭环

过滤无结果时 MUST 有空态提示（如"无匹配章节"），MUST NOT 无任何反馈。

#### Scenario: 无匹配

- **WHEN** 用户输入的过滤词无匹配项
- **THEN** 列表区域显示空态提示，说明当前过滤词
