# Design

## 决策与现状

2026-11-02 owner 批准以「创作者的平台名称」替换 F7 原作者聚合查询及 2026-11-01 的 B2 详情入口。旧实现尚未提交，原 B2 测试/截图只作历史证据，不能证明新设计完成。F6 保留。

收藏右栏在 `local_favorites_page.dart` 的 `_FilterSectionPanes`；单选集合为 authorFilters。`favoriteAuthorValues` 配合 `local_favorites_author_aliases` 处理已有作者合并，原值仍在收藏 tags/author 中。当前 State.comics 受文件夹影响，平台名称不能只从它收集。现有 LocalFavoritesManager 全收藏接口和收藏 store generation 可复用，原始身份仍为 `(id, comic_type)`。

## D1 搜索方案（F6 保留）

appdata settings 的 `searchProfiles` 保存 id、名称、来源顺序、启用状态、每源 options，另存默认 id。名称 trim 后非空、≤30 字符、大小写不敏感唯一。未知来源忽略，无法恢复的选项按当前 schema 回退默认值。未选方案保留原全局 `searchSources`/`defaultSearchTarget` 行为；聚合结果与分页使用同一逐源选项快照。Explore 设置管理与搜索入口选择 UI 保留。

## D2 移除已废止链路

移除新增 AuthorSearchAction、详情作者跨平台按钮和无单源 target 时的作者聚合 fallback；原标签点击/复制/快捷方式恢复原行为。移除新增 AuthorSearchIntent/Query/Resolution、ComicSource.authorSearchConverter、parser 的 `search.author` 解析及聚合页作者专用分支。删除只为该废止行为服务的测试/翻译词条，不删除 F6 内容和既有单源功能。不用整文件 reset 覆盖共享 F6 改动。

## D3 平台名称数据

名称树 = 全部本地收藏中已知关联的名称 + 用户手动名称 - 用户明确隐藏的已知名称。只从本地数据推导，不请求平台发现别名。

- 已知名称：逐收藏读取 author namespace 原始 tag（无 tag 时沿用既有作者字段 fallback）；用与现有筛选一致的规范化原名及已确认 aliases 判断它属于哪个创作者，展示/查询仍使用原平台名称（仅 trim 外侧空白，不翻译、不拼接语法）。从 comic.type 对应具体 ComicSource key 归源，不按平台显示名猜测。无可恢复来源 key 的旧记录不猜配其他来源。
- 数据集合必须来自全部本地收藏，不受当前文件夹、系列、关键词、阅读状态、标签筛选限制；保留不同来源身份。同一作品在不同文件夹保存了不同作者元数据时也必须保留原名：当前正确入口为 manager.allComics() 逐文件夹行，而 getAllComics()/Async 按(id,type)去重，不能用于完整原名收集。重复的 `(sourceKey, 搜索名称)` 在当前创作者下只显示一行。
- 手动名称和隐藏记录使用独立 implicitData key `creator_platform_names`，通过 appdata.updateImplicit 持久化；缺省/坏条目容错，不更改收藏数据库或原始作者。建议 versioned records `{version: 1, entries: [{anchor, sourceKey, name}], hidden: [{anchor, sourceKey, name}]}`，实现可作等价封装。
- anchor 是已有原始作者的规范化名，显示归属按当前 aliases 解析。添加时优先取与所选创作者同名的已知原名，否则选其关联原名的稳定排序首项；没有可用原名时用当前所选名称。名称并入另一创作者后记录随原名解析，不依赖易变的显示名作唯一身份。撤销合并后手动记录跟随原 anchor，不复制到多个创作者，也不删除。自动名称的隐藏记录分别保留原 anchor，避免影响其他创作者。
- 同来源允许多个不同名称；仅 trim 后完全相同者去重，大小写/假名/括号差异不做推断。编辑/删除自动收集行时保存隐藏记录，编辑后的值保存为手动行，刷新/重启不得复活旧行；显式重新添加可恢复同一名称。
- 每次写入使用最新草稿并保护页面/数据库/数据目录归属；快速切换创作者后，尚未完成的编辑不得写到新选中者。写入失败保留旧有效状态并提示，不显示成功。收藏变更、合并变更后更新派生树，避免 build 每帧全库读取。

## D4 面板与管理交互

- 在「创作者」列表底部增设紧邻的「平台名称」区，显示唯一选中创作者名称及平台树。仅零选/多选时隐藏该树，不替代或改变原作者筛选。无名称时显示空状态和「添加名称」。
- 来源分组标题只负责展开/折叠；名称行明确可点击搜索，提供可见的更多/编辑/删除动作与「添加名称」入口，不能依靠右键发现。添加/编辑表单选择已安装可搜索来源并填写非空名称；允许给同一来源增加多个名称。删除仅影响映射/隐藏记录，不删漫画、作者或收藏。
- 来源显示当前平台名，绑定实际 source key；同显示名来源须可区分。已保存来源失效时保留手动记录，显示「来源不可用」并禁用搜索；可改到其他有效来源，恢复同一 key 后重新可用。不能默默搜索别的来源。
- 宽屏作者区 header/search/list/tree 共享有界滚动空间，保留原标签区和 splitter；260px 窄侧栏长名字可换行并可查看全文，不挤出父布局。仅选中者树出现，平台分组/名称可 Tab 定位和 Enter/Space 操作。
- ≤900px 复用现有筛选弹窗/面板中的同一树组件，根据弹窗内实时作者选择显示，不能只依赖底层页面旧 authorFilters；不新造壳层。关闭/返回保留原已应用筛选，搜索返回不重置收藏选择或滚动位置。

## D5 普通来源搜索

点击名称创建普通 `SearchResultPage(text: 名称, sourceKey: 绑定来源)`，选项使用该来源 SearchPageData 当前正常默认值，与在该来源搜索相同关键词的效果一致。不得调用 handleClickTagEvent、author converter、聚合方案或拼接 `author:`；不向同名平台/其他来源发送请求。分页继续走既有单源通道，保留关键词与选项。来源不可用/不支持普通搜索时清晰提示且零请求。

选中创作者、显示/展开树和维护映射不发网络请求。搜索结果由平台普通检索决定，可能包含关键词相关作品，不承诺作者精确过滤。实际平台验证需区分“正确来源/关键词已送达”与“平台确实返回作品”；受控 fixture 不能代替 owner 实际来源的内容命中证明。

## 框架容纳检查

沿用 design-spec 第2–4节 token/断点与第7.3节内容区，平台树嵌入已有收藏作者区，不新增 surface/壳层/断点例外。使用语义颜色、1px 分隔线、Material 控件和现有 `.tl` 双语。阅读器无改动，主题规则不变。

## 验证

覆盖名称编解码/持久化、手动 CRUD、自动收集/隐藏/恢复、同源多名称、多源同显示名、alias 合并/重置、筛选独立性、来源失效、页面/数据库切换时写入归属、生产收藏右栏及窄屏入口、键盘和分页。复跑 F6/收藏/作者管理/原单源快捷方式回归，analyze 50 项零新增；GUI 隔离数据截证只留 `/tmp`，测试源标明为受控验证。
