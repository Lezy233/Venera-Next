# Proposal

## Why

BACKLOG F6+F7：当前聚合搜索只读取一组全局来源并为每个来源使用默认选项，无法保存不同检索目的的来源组合、顺序和过滤条件；作者标签点击也依赖单源自定义跳转，不能跨来源检索作者作品。

## What Changes

- 新增命名的聚合搜索方案，保存来源顺序及每个来源可恢复的搜索选项；支持新建、重命名、更新、删除、选择和默认方案。
- 聚合搜索页按方案加载各源，并把方案选项传递到结果页，保留现有全局来源设置作为兼容默认。
- 从漫画详情的标准作者标签进入跨源作者搜索；只对明确声明支持作者查询的来源执行，其他来源跳过并给出结果状态。
- 新增必要的来源能力/查询转换契约、持久化迁移与来源卸载清理。
- 新增 UI 文案经 `.tl`，补齐 `zh_CN`、`zh_TW`。

## Out of Scope

- 不假设所有源都接受统一 `author:` 字符串；不对不支持作者查询的源强行拼接关键词。
- 不改变现有单源搜索、搜索历史、作者快捷方式和命令中心行为。
- 不做作者实体合并、别名推断或跨源结果去重。
- 不新增服务端搜索协议；源能力由现有 source/js 扩展点提供。
