# Spec Delta

## Purpose

对 `components/save-feedback` 的增量修订：保存反馈不仅不占用正文布局，还必须在所有壳层形态（桌面顶栏/移动无顶栏/单栏/双栏）下完整可见，不被任何壳层元素遮挡或裁剪。

## MODIFIED Requirements

### Requirement: 保存反馈可见性

覆盖层呈现 MUST 保留三态反馈：保存中（进行中指示）、保存成功、保存失败（含重试入口）；用户 MUST 能在保存进行中明确感知保存状态。保存反馈 MUST NOT 被壳层元素（桌面顶栏、工具栏等）遮挡或裁剪，在任何接入页面中完整可见。

#### Scenario: 设置页切换作用域

- **WHEN** 用户在「设置 → 阅读」切换作用域触发保存
- **THEN** 「已保存」反馈完整呈现，不被顶栏遮挡

#### Scenario: 就地编辑右栏保存

- **WHEN** 用户在双栏右栏就地编辑页触发保存
- **THEN** 保存反馈完整呈现于右栏可视区内

#### Scenario: 保存失败

- **WHEN** 保存失败
- **THEN** 覆盖层反馈 MUST 显示失败状态并提供与现状一致的重试入口
