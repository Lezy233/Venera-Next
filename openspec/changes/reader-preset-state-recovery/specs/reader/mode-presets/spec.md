# Spec Delta

## ADDED Requirements

### Requirement: 按作用域恢复当前方案

系统 MUST 将成功应用的方案ID按global、当前deviceId及(sourceKey,comicId)漫画身份分别持久化，MUST 与方案参数同一事务保存。设置页和快捷面板 MUST 在重新进入和应用重启后读取目标作用域的同一引用；同值不同方案 MUST 保留用户所选ID。缺省/损坏/失效记录 MUST 安全显示无且不改参数。系统 MUST NOT 自动把旧参数关联到未曾明确选择的方案。

#### Scenario: 保存后重进与重启

- **WHEN** 用户在默认作用域应用「双面翻页」，保存成功，离开重进并重启应用
- **THEN** 当前方案仍显示「双面翻页」且实际组合参数保持；切换设备或漫画作用域不会显示默认层引用

#### Scenario: 漫画与设备身份隔离

- **WHEN** 用户在来源A的漫画1应用甲，在来源B同id漫画应用乙，或切换设备身份
- **THEN** 各作用域恢复各自记录，不能串用；阅读器面板与该漫画全量设置显示一致

### Requirement: 当前方案与实际组合一致

显示当前方案 MUST 同时满足引用有效及方案声明的有效19键与当前作用域生效值匹配，MUST 沿用既有模式求值和漫画override语义，不得用强制auto=false的快照掩盖实际变更。无有效键的方案 MUST NOT 匹配。重命名/删除/更新、作用域切换及参数变更 MUST 触发重新校验；校验 MUST NOT 自动应用方案。

#### Scenario: 手动修改与非组合项

- **WHEN** 用户应用方案后手动修改一个方案包含的布局/模式/手势键
- **THEN** 参数不匹配时当前方案显示无；仅修改亮度等方案外键时仍显示原方案

#### Scenario: 方案生命周期

- **WHEN** 当前方案重命名、被删除或更新为另一组值
- **THEN** 分别显示新名称、无或按新值校验的结果，已有作用域参数不因显示校验而改变

### Requirement: 清除选择与保存失败

选择无 MUST 仅清目标引用，不改阅读参数或启用状态；重置作用域 MUST 清目标引用且不影响其他层。保存成功 MUST 以appdata.json及当前要求的syncdata.json全部写入成功为准。保存失败 MUST NOT 显示已保存，MUST 恢复本操作仍拥有的参数及引用并尝试补偿持久化；不得仅清引用保留失败参数。重试 MUST 可用。异步完成 MUST 校验原页面/作用域/设备或漫画/数据目录归属，不得覆盖新归属。

#### Scenario: 无与重置

- **WHEN** 用户选择无，随后重进，或重置当前作用域
- **THEN** 当前方案保持无；选择无本身保留实际参数，其他层引用和参数不变

#### Scenario: 写入失败与切换

- **WHEN** 应用方案发生IO失败，或保存期间切换目标身份
- **THEN** 失败无成功提示且不能留下新引用假成功；旧操作不串写新目标，用户可在有效原目标重试


### Requirement: 部分持久化与恢复未完成

任何要求文件失败 MUST 视为本次保存失败，即使其他文件已成功也 MUST 对原目录作一次有界补偿，把最新恢复后有效草稿写入全部要求文件。补偿 MUST 仅恢复本操作拥有的字段/引用，保留并发无关修改及后续合法接管，MUST NOT 将旧快照整份覆盖。只有全部补偿写成功才可声称耐久恢复完成。

#### Scenario: 主文件成功而同步投影失败

- **WHEN** appdata.json已保存新参数与引用，但syncdata.json失败，补偿随后成功
- **THEN** 两文件均写回最新恢复草稿，重载恢复旧有效参数/引用，保留无关更新，本次仍报告失败而非已保存

#### Scenario: 补偿失败与重试恢复

- **WHEN** 首次保存和补偿均失败，用户重进页面并在解除文件故障后点击重试恢复
- **THEN** 补偿完成前同目标持续显示恢复未完成、选择无/未确认且暂停新方案操作；重试仅耐久恢复旧有效状态，完成后解除暂停，用户须明确再次选择方案才重新apply

#### Scenario: 恢复未完成时故障退出

- **WHEN** 已明确报告恢复未完成，但用户强制退出后重启
- **THEN** 按实际appdata.json及现有参数校验加载，不保证跨进程回滚、不自动重放失败操作、不补发历史已保存；无效引用或可证明的不一致显示无/既有错误
