# Spec Delta

## ADDED Requirements

### Requirement: 按作用域恢复当前方案

系统 MUST 将成功应用的方案ID按global、当前deviceId及(sourceKey,comicId)漫画身份分别持久化，MUST 与方案参数同一事务保存。设置页和快捷面板 MUST 在重新进入和应用重启后读取目标作用域的同一引用；同值不同方案 MUST 保留用户所选ID。缺省/损坏/失效记录 MUST 安全显示无且不改参数。系统 MUST NOT 自动把旧参数关联到未曾明确选择的方案。

#### Scenario: 保存后重进与重启

- **WHEN** 用户在默认作用域应用「双面翻页」，保存成功，离开重进并重启应用
- **THEN** 当前方案仍显示「双面翻页」且实际组合参数保持；切换设备或漫画作用域不会显示默认层引用

#### Scenario: 漫画与设备身份隔离

- **WHEN** 用户在来源A的漫画1应用甲，在来源B同id漫画应用乙，或切换设备身份
- **THEN** 各作用域恢复各自记录，不能串用；阅读器面板与该漫画全量设置显示一致

### Requirement: 当前方案与实际组合一致

显示当前方案 MUST 同时满足引用有效及方案声明的有效19键与当前作用域生效值匹配，MUST 沿用既有模式求值和漫画override语义，不得用强制auto=false的快照掩盖实际变更。无有效键的方案 MUST NOT 匹配。重命名/删除/更新、作用域切换及参数变更 MUST 触发重新校验；校验 MUST NOT 自动应用方案。

#### Scenario: 手动修改与非组合项

- **WHEN** 用户应用方案后手动修改一个方案包含的布局/模式/手势键
- **THEN** 参数不匹配时当前方案显示无；仅修改亮度等方案外键时仍显示原方案

#### Scenario: 方案生命周期

- **WHEN** 当前方案重命名、被删除或更新为另一组值
- **THEN** 分别显示新名称、无或按新值校验的结果，已有作用域参数不因显示校验而改变

### Requirement: 清除选择与保存失败

选择无 MUST 仅清目标引用，不改阅读参数或启用状态；重置作用域 MUST 清目标引用且不影响其他层。保存失败 MUST NOT 显示已保存或恢复为新方案已成功应用；重试 MUST 可用。异步完成 MUST 校验原页面/作用域/设备或漫画/数据目录归属，不得覆盖新归属。

#### Scenario: 无与重置

- **WHEN** 用户选择无，随后重进，或重置当前作用域
- **THEN** 当前方案保持无；选择无本身保留实际参数，其他层引用和参数不变

#### Scenario: 写入失败与切换

- **WHEN** 应用方案发生IO失败，或保存期间切换目标身份
- **THEN** 失败无成功提示且不能留下新引用假成功；旧操作不串写新目标，用户可在有效原目标重试
