## ADDED Requirements

### Requirement: 作者优先组内手动模式

本地收藏和系列视图 MUST 提供明确的作者优先、同作者手动模式；作者按名称稳定升序、缺作者置末，同组顺序 MUST 可手动调整并持久化。作品 MUST 按现有作者标签优先、首位有效作者和人工alias规则归组，MUST NOT 因排序修改作者或自动归并跨源实体，多作者作品 MUST 只出现一次。

#### Scenario: 作者优先且组内调整

- **WHEN** 用户将作者甲的作品甲二移到甲一之前，作者乙有另一作品
- **THEN** 显示甲二/甲一再乙作品，作品作者和元数据保持，跨作者移动被拒绝或限制在原组

### Requirement: 视图顺序与既有排序隔离

全部收藏、各文件夹及各系列 MUST 各自独立保存新模式顺序，MUST 使用带类型的作用域与完整(comic_id,comic_type)作品身份；MUST NOT 覆写旧纯手动顺序或其他模式配置。切换模式、重进及重启 MUST 保留。新增成员 MUST 稳定追加组末，筛选 MUST NOT 丢失隐藏成员顺序。

#### Scenario: 同身份跨视图

- **WHEN** 用户在文件夹甲调整同作者作品，再进入文件夹乙及同名系列，然后重启返回甲
- **THEN** 其他视图顺序保持独立，甲恢复已存顺序，同id不同来源仍各自独立

### Requirement: 排序生命周期与可靠写入

文件夹改名 MUST 保留其顺序，删除重建 MUST NOT 复活旧序；系列和收藏成员变化 MUST 按归属清理，不影响其他视图。排序 MUST 在原数据库归属下基于最新身份事务写入，仅改变本组位置；失败 MUST 回滚且反馈，MUST NOT 丢并发CRUD或写入新目录/连接。网络收藏服务器 MUST NOT 接收本地排序写回。

#### Scenario: 排队目标变动或失败

- **WHEN** 移动排队期间目标被删除、作者分组改变、目录切换或SQLite写入失败
- **THEN** 操作安全拒绝或回滚，原作者/作品/其他作用域保留，用户收到可恢复错误且无成功误报

### Requirement: 可操作性与既有交互保护

排序编辑 MUST 支持拖动及鼠标单击/键盘可用的上下移替代，首尾无效操作禁用，同身份焦点保持。主视图 MUST 保留收藏点击偏好、多选、右键、独立按钮及原筛选/系列/F7行为。UI MUST 遵循既有设计契约，新文案 MUST .tl并提供简繁翻译。

#### Scenario: 无拖动排序与返回

- **WHEN** 用户经Tab及Enter/Space调整同组作品并返回仍有筛选的收藏页
- **THEN** 只调整组内顺序，不打开详情或清空原筛选/选择，当前作品和来源身份正确
