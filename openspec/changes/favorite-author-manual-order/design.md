# F10 设计

## D1 已确认的产品语义

Owner于2026-11-04选择「每个文件夹/系列独立记忆」，以下按已提交建议锁定为本轮契约；不再等待额外确认：

1. 范围仅本地收藏（全部/具体文件夹）及系列；不改网络收藏服务器。各视图独立记忆，全部视图也有自己的作用域，文件夹与系列即使同名也互不覆盖。
2. 沿用favoriteAuthorValues：权威作者namespace标签优先，按存储顺序取首位有效作者，经既有normalize及用户明确alias映射；没有标签时才回退已有author字段。多作者作品只出现一次，不复制到多个组。缺作者组最后。
3. 作者名称按现有大小写归一后的比较规则升序，再以原规范化名称稳定区分仅大小写不同的组；同名显示作者可以放同一显示组，但不产生实体归并，不跨源猜测别名。原authorAsc/Desc语义保持。
4. 新模式不复用或改写原纯手动display_order。组内已存身份按持久顺序，未排序的新成员按确定顺序追加组末（收藏时间升序，再稳定复合身份）。首次无记忆时，以该视图已有稳定成员顺序为种子，不按标题重新洗牌。
5. 作者/alias变化后重新求组，不改元数据；同一作品保留自己的视图顺序记录，新组内按该记录稳定求值。不将旧作者的全部组序复制到其他组。手动顺序按作品身份存储，作者名不是持久主键。

## D2 身份、存储与生命周期

新增独立的本地展示排序记录，建议放收藏SQLite现有事务域（新表允许，无依赖变动），作用域采用带类型的稳定身份：all、folder+原文件夹身份、series+稳定ID。作品键用既有完整(comic_id,comic_type)，不得用标题、hashCode或缺失来源时的Unknown显示名作主键。旧库无记录时保持原模式，不自动切到新模式。

同一身份在多个文件夹出现时在全部视图只显示一次，沿用现有getAllComics去重；不同来源同id保持不同记录。文件夹改名须在同一事务迁移其独立顺序；删除文件夹/系列清理自身记录，重建同名不得恢复旧序；删除一个文件夹中的成员不能破坏其他视图顺序，彻底移除收藏或系列成员时按归属清理。新增/移出/重新加入成员规则确定且不复活其他已删数据。

新排序模式选择本身按视图持久化，系列也使用稳定seriesId且不与folder同名键冲突。现有模式和过滤偏好不更名或重置。沿用既有整库备份/数据目录切换；库初始化、导入/替换、导出和恢复若涉及新表，必须保证新排序记录安全兼容，不丢现有收藏/系列/alias。单文件夹旧格式无需强塞不支持的扩展；不宣称旧格式能保留其未承载的新顺序。

## D3 排序编辑与筛选

主视图提供明确新模式标签和排序入口。可采用既有ComicReorder编辑器的局部扩展：先选择作者组，再编辑该组完整成员；或按作者分节的编辑器。无论选择何种实现，须保持作者外序，跨作者拖动被拒绝并反馈，不能通过拖动改作者或组序。提供上/下移等鼠标与键盘替代，首尾禁用、同身份焦点；Reverse若保留只反转当前组，不能反转作者外序。

筛选/搜索只限制主视图显示，不改变存储作用域；进入编辑器明确编辑该视图的完整作者组，隐藏作品不得因过滤而删序或重排到其他组。返回后原过滤、滚动与多选不清空。可在已存在的排序编辑页添加必要作者选择/简短范围说明，不重建收藏布局。

组内卡片继续展示真实标题/来源，不触发详情/直读；主视图遵守B4已验收命中与收藏偏好、多选/右键/独立按钮规则。系列加入/移出和原纯手动排序继续可用；F7作者名称树/筛选及F11未实现区域保持。

## D4 写入、失败与并发归属

manager使用已有_mutate/AppDataOperations与SQLite事务。操作捕获scope、复合作品ID、相邻目标ID和原目录/manager连接generation；实际入队后验证原scope仍存在、两者仍在原作者组，再基于最新成员/rank计算，不写页面旧完整对象快照。并发新增/删除/改名/作者或alias变化不得丢失或被复活；组变化或目标失效时拒绝移动并本地化提示刷新。

同一事务仅改当前scope内当前组作品的位置，不改收藏字段/原display_order/系列成员/alias/其他scope；保存失败事务回滚旧序，不显示Saved，错误靠近编辑器且可重试。复用SettingsSaveState或既有保存反馈机制，页面关闭和排队写入归属明确，数据目录/连接替换后旧结果不得写新库或假更新新页。已有网络同步/收藏读写不能携带本地排序去调用远端API。

## D5 UI契约

design-spec.md §1–6为外观契约；沿用token、断点、ColorScheme与已有菜单/筛选控件。ui-ux-pro-max仅用于既有命中/拖动冲突/键盘焦点/禁用/错误反馈/缩放检查，不生成新视觉系统。新文案.tl并补zh_CN/zh_TW，阅读器chrome跟主题不新增例外。
