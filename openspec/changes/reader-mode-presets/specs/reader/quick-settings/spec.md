# Spec Delta

## Purpose

（reader-mode-presets change 对快捷设置面板的增补：默认集新增「方案」切换项，其余 Requirement 不变。）

## MODIFIED Requirements

### Requirement: 高频项极简集合

阅读器内设置面板 MUST 只包含高频项（默认集：阅读模式、**方案**、亮度、翻页方向、缩放、翻页动画、缩略图开关），MUST NOT 整页复用全量设置列表。注：默认集不含背景色——阅读背景跟随主题是设计契约（现代极简，深色内容区为二期），不设为用户偏好。方案项位于阅读模式项之后，是整套配置的一键切换入口（见 reader/mode-presets）。

#### Scenario: 调整亮度

- **WHEN** 用户阅读中打开设置面板并调整亮度
- **THEN** 用户在 3 秒内完成操作，无需滚动或分组查找

#### Scenario: 需要高级项

- **WHEN** 用户需要修改预加载数等高级项
- **THEN** 面板提供"全部设置"入口，跳转到设置 → 阅读且作用域为"此漫画"

#### Scenario: 切换整套方案

- **WHEN** 用户阅读中打开设置面板并切换方案
- **THEN** 方案值应用到当前漫画作用域，操作在 3 秒内完成，无需进入全量设置页
