# Spec Delta

## Purpose

（本 delta 仅登记键盘快捷键 change 对设置信息架构的新增约束：快捷键编辑页的分类归属。）

## ADDED Requirements

### Requirement: 快捷键设置归属 APP 分类

「快捷键」设置页 MUST 位于 APP 分类下（App 级行为偏好），MUST NOT 单独占据主导航分类或归入浏览/阅读分类。

#### Scenario: 查找键位设置

- **WHEN** 用户想在设置中修改快捷键
- **THEN** 该页面 MUST 位于 APP 分类下，与「启动时打开哪个页面」等其他 App 级偏好同处一类
