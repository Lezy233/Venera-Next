# favorites/sidebar-sections Specification

## Purpose
规定收藏导航中本地、系列与网络分组的独立折叠、可靠状态记忆、当前位置提示及键盘操作，并保持当前内容、多选、管理菜单和来源请求等既有业务行为，确保桌面侧栏与窄窗选择器一致。

## Requirements

### Requirement: 三组独立折叠与管理动作

收藏侧栏 MUST 保持本地、系列、网络三组及既有顺序，各组 MUST 独立展开或折叠，默认展开。折叠 MUST 仅隐藏该组子条目，保留标题及既有管理入口；本地All也属于本地子条目。点击标题主体或箭头 MUST 切换一次；管理菜单和网络设置 MUST 为独立命中区，不得同时切换或选择目录。空组 MUST 仍可操作组头。

#### Scenario: 收起本地不影响其他组

- **WHEN** 用户点击本地标题主体收起该组
- **THEN** 本地All与文件夹隐藏，系列和网络及其展开状态保持；不调用选择回调或关闭文件夹选择器

#### Scenario: 收起时使用管理入口

- **WHEN** 用户在已收起组的管理菜单或网络设置上点击
- **THEN** 仅执行该入口原有动作，组状态不变、不额外导航或请求来源

### Requirement: 键盘与可访问性

组头 MUST 支持Tab焦点及Enter/Space切换，聚焦时Left收起、Right展开且幂等，不得拦截无关区域键盘。MUST 有可见hover、pressed和focus反馈，语义提供组名、展开状态及当前状态。折叠条目 MUST 不参与焦点或可访问性遍历；被隐藏条目的焦点 MUST 回到该组头。

#### Scenario: 键盘折叠与恢复

- **WHEN** 用户聚焦系列组头，按Left两次，再按Right一次
- **THEN** 首次收起、再次Left不反转、Right展开；焦点保持可用，不触发系列选择或菜单

### Requirement: 保留当前身份与内容

折叠 MUST 保留当前收藏内容实例及其选择、筛选、滚动等有效状态，不得改变收藏身份、页内多选、作者栏独立排序或引发网络内容重新请求。当前组折叠时 MUST 在组头以选中样式和当前条目名称明确当前位置，完整名称可由tooltip和语义读取。系列id或来源key而非显示名 MUST 决定归属；无有效选择不标记当前组。

#### Scenario: 折叠含多选内容的当前组

- **WHEN** 用户在本地文件夹内容已选中两部漫画后收起本地组，再展开
- **THEN** 同一内容及两项选择保持，折叠时组头显示当前文件夹，展开后原条目仍选中；Escape退出多选及漫画主动作仍沿原规则执行

#### Scenario: 同名系列和来源

- **WHEN** 系列与网络来源显示名相同，用户当前选中该系列并收起三组
- **THEN** 只有系列组显示当前标记与该系列名，不按名称误标本地或网络，内容不切换

### Requirement: 可靠记忆与入口一致

三组状态 MUST 作为本机收藏导航偏好按稳定组标识可靠持久化，桌面侧栏和窄窗选择器 MUST 共享一致状态，重开和真实重启保持。缺失或坏整体 MUST 回退全部展开，坏单项 MUST 单独回退展开，保留其他有效项与不相关数据。快速连续切换 MUST 保存最终意图，保存失败 MUST 可见且可重试，不得假报成功、覆盖较新意图或遗失其他设置；已接受保存 MUST 按既有生命周期完成。

#### Scenario: 损坏单项与重启

- **WHEN** 保存数据中local为false、series为非法字符串、network为true后重新初始化
- **THEN** 本地收起，系列与网络展开，不相关字段保持；再次切换并成功保存后，进程重启读到最终三组状态

#### Scenario: 混合连续修改后保存失败

- **WHEN** 用户快速切换不同组，保存失败后使用重试，并在保存期间关闭选择器或离开页面
- **THEN** 失败可见且未假报已保存，较新意图不被旧结果覆盖，成功重试保存最终三组值；离页不丢已接受保存，不更新已销毁控件

### Requirement: 现有设计与业务保护

新增UI MUST 遵守design-spec.md，使用现有token与主题语义角色，MUST NOT 扩大为整体美化。新文案 MUST .tl并提供zh_CN/zh_TW。最窄侧栏、窄窗与大文字 MUST 保留可用标题、摘要和独立管理入口，不溢出；减少动画偏好 MUST 生效。收藏右键/菜单、来源配置、作者/标签过滤和F10作者栏状态与排序 MUST 保持。

#### Scenario: 窄栏大字与深色主题

- **WHEN** 使用160宽侧栏或390宽窗口、1.6文字和深色主题，收起含长名称当前项的组
- **THEN** 当前名称可完整获取、组头和菜单可分别操作，无布局溢出，焦点和选中状态可见，业务状态不变
