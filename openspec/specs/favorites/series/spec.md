# favorites/series Specification

## Purpose
收藏系列用于把不同来源的已收藏作品按用户意图手动组织起来，并与现有收藏文件夹保持正交。

## Requirements

### Requirement: 系列数据与身份

系统 MUST 持久化系列实体及其 `(comic_id, comic_type)` 成员映射。系列名 MUST 唯一（忽略首尾空白后大小写不敏感），成员 MUST 幂等；系统 MUST NOT 根据标题、作者或标签自动加入系列。

#### Scenario: 跨来源成员

- **WHEN** 用户把来源 A 与来源 B 的同名作品分别加入「待追」系列
- **THEN** 系列保存两条不同 `(comic_id, comic_type)` 成员，且不会自动合并或覆盖

### Requirement: 系列管理

系统 MUST 支持新建、重命名、删除和排序系列。删除系列 MUST 保留收藏及文件夹；重命名和排序 MUST 在事务中完成并通知收藏观察者。

#### Scenario: 删除系列

- **WHEN** 用户删除「待追」系列
- **THEN** 系列映射被删除，原作品仍存在于原收藏文件夹，收藏观察者收到一次刷新通知

### Requirement: 成员管理

用户 MUST 能把一个或多个已收藏身份加入或移出系列。加入已存在成员 MUST 不产生重复记录；从系列移出 MUST 不影响收藏文件夹。删除收藏身份后 MUST 清理不再存在的系列成员。

#### Scenario: 重复加入与移出

- **WHEN** 用户两次把同一收藏加入系列，再从系列移出
- **THEN** 系列始终只有一条成员记录，移出后该收藏仍保留在原文件夹

### Requirement: 系列视图

收藏页 MUST 能进入系列并显示该系列全部成员；系列视图 MUST 保留跨来源的不同 `(id, comic_type)` 身份，不得复用 All 视图按身份去重后丢失成员的结果。

#### Scenario: 系列视图保留来源身份

- **WHEN** 系列包含两个来源身份不同但标题相同的作品
- **THEN** 系列视图显示两个成员，且各自保留来源信息

### Requirement: 兼容与同步

旧收藏数据库升级后 MUST 保留现有文件夹、顺序、同步链接和收藏数据。系列表 MUST 随现有本地收藏数据库整体同步；旧版导入数据没有系列成员时 MUST 保持未分组。

#### Scenario: 旧库升级

- **WHEN** 应用打开没有系列表的旧收藏数据库
- **THEN** 自动创建空系列结构，既有文件夹和收藏数量保持不变，导入作品不被自动加入系列

### Requirement: UI 语言与契约

所有新用户可见文案 MUST 通过 `.tl` 提供，并在 `assets/translation.json` 同时提供 `zh_CN` 与 `zh_TW`。系列 UI MUST 遵循 `design-spec.md` 的 token、断点、浅色 surface 和 1px 分隔线规则。

#### Scenario: 双语 UI

- **WHEN** 用户在中文简体或繁体环境打开系列管理
- **THEN** 系列入口、操作、空状态和错误提示均来自对应翻译词条，界面不出现硬编码文案

### Requirement: 收藏操作可发现性

本地收藏文件夹 MUST 提供 secondary-click 操作菜单；文件夹内容页顶部「更多」菜单 MUST 提供进入多选的可见入口。多选状态 MUST 提供 `Escape` 和可见关闭按钮两种退出路径，且 `Escape` MUST 清空选择而不触发窗口级返回。

#### Scenario: 文件夹右键操作

- **WHEN** 用户在本地文件夹侧栏行上 secondary-click
- **THEN** 在指针位置出现包含该文件夹相关操作的菜单，左键选择行为不被改变

#### Scenario: 从更多菜单进入多选

- **WHEN** 用户打开本地收藏内容页顶部「更多」并选择「选择漫画」
- **THEN** 页面进入多选状态并显示选中数量和批量操作菜单，无需先对某一漫画打开右键菜单

#### Scenario: Escape 退出多选

- **WHEN** 多选状态下用户按下 `Escape`
- **THEN** 所有选中项被清除、页面退出多选状态，窗口导航栈不发生返回

### Requirement: 批量加入系列

多选操作 MUST 提供「加入系列」动作。用户确认目标系列后，所有选中且仍有效的收藏身份 MUST 一次性加入该系列；操作成功 MUST 显示数量反馈。无可用系列时 MUST 提供创建系列的引导或明确提示。

#### Scenario: 批量加入系列

- **WHEN** 用户选中三部漫画并选择系列「待读」确认加入
- **THEN** 三个收藏身份被加入「待读」，显示已加入数量，原文件夹和选中项不被意外删除
